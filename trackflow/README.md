# Skycast

A calm, responsive weather dashboard powered by OpenWeatherMap.

## Run locally

1. Create an OpenWeatherMap account and copy your API key.
2. Add `VITE_OPENWEATHER_API_KEY=your_key` to `trackflow/.env`.
3. Run `npm install` then `npm run dev` from the `trackflow` directory.

Features include city search, live current conditions, a five-day forecast, Celsius/Fahrenheit units, and recent searches saved in local storage.
